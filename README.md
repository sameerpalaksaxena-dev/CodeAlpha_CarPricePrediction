# Car Price Prediction

This project predicts used car selling prices using Linear Regression.

## Dataset
Vehicle dataset from CarDekho (Kaggle)

## Steps
- Data cleaning and feature engineering (Car Age calculated from Year)
- Categorical encoding (Fuel Type, Seller Type, Transmission)
- Trained a Linear Regression model
- Evaluated using R2 Score and MAE

## Results
- R2 Score: 0.85
- MAE: 1.21

## Key Insight
Present showroom price and car age are the strongest predictors of selling price.
